# 随访字段字典

随访表 `patient_follow_up_history` 的 7 个病历模块各存一段老系统的 JSON。下表是字段名 → 中文名 / 单位，**业务已确认（2026-10-05，见 `docs/待确认清单-v1.xlsx`）**。
代码里的字典：`com.wenwen.util.VisitFieldDict`（访视详情按它分组显示）。字典里没有的字段，访视详情放在「其他字段」里按原字段名显示，不会丢。

通用约定：
- 每个模块的 `finish` 表示前端显示「是否填完」，不代表每一项都已填写；不显示。
- 带 `Wx` 的字段是「未查」标记，`true` = 未查（`xcgWx` 是 `{化验字段: true/false}`）。值为空且标记未查时显示「未查」。
- 化验单 / 影像图片地址（ooso.oss-cn-hangzhou.aliyuncs.com）可直接显示。
- 检验参考范围未确定，暂不标红异常值。

| 分组 | 字段 | 中文名 | 单位 |
|---|---|---|---|

**西药**（`xyList`，每行一条）：`drugName` 药品名称、`goodsName` 商品名称、`category` 药品类别、`company` 生产厂家、`dosis+dosisUnit` 剂量、`drugDelivery` 给药方式、`drugFreq` 给药频次、`startTime~endTime` 用药起止、`tygc` 调药过程、`tyyy` 调药原因、`cost` 花费

**中药饮片**（`cyList`，每行一条）：`zz` 证型、`fj` 方剂、`bccy` 草药、`qtbccy` 补充草药

**中医外治**（`zywzList`，每行一条）：`name` 方法、`part` 部位、`qt` 其他

不良事件（SAE类别、采取的措施、其他措施、不良事件详情）也存在 `blsj`（已确认）。
`saeList`、`otherAction`、`eventDetail` 老系统库里从未存过，字段名由本系统自定义（业务同意）：
SAE类别为字符串数组，其他措施、不良事件详情为文字。老系统不认识这 3 个 key；若在老系统里再编辑该随访，可能被老系统覆盖丢失。
没填的字段老系统不写 key（如没填结束日期就没有 `endDate`）。
