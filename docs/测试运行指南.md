## 工具身份与测试开关

使用独立 Java8 工具链，不替换系统默认 Java。将本机实际 JDK8/Maven 安装位置代入：

```sh

export PATH="$JAVA_HOME/bin:<实际Maven目录>/bin:$PATH"
java -version

```

三条输出必须分别确认 Java8、javac8 和 Maven 使用 Java8。本次云端验证为 Amazon Corretto 8.504.04.1（1.8.0_504-b04）及 Maven 3.9.16；不代表其他机器已配置。现有 Lombok 1.18.0/编译器配置不变，不用 Java17 替代。

POM 已移除 Surefire 硬编码 `<skip>true</skip>`，沿用 Spring Boot 2.2.0.RELEASE 管理的 Surefire 2.22.2 和既有 JUnit Jupiter。原配置即使 Maven 退出0，也只输出 `Tests are skipped`、没有本次测试报告，不能据此宣称通过。不要添加 skip 参数或依靠 `-DskipTests=false` 覆盖原硬编码开关。

## 历史 P00a 正例：准确发现十个方法

本节固定于 P00a 实现快照，仅供仪器历史复验。P01b 已新增用例并替换旧 CRP 切点，当前计数须按下方 P01b 清单核对，不能把历史十方法作为未来模块总数。

从仓库根进入模块，记录本次起止时间和退出码：

```sh
cd raapi
start=$(date -u +%Y-%m-%dT%H:%M:%SZ)
mvn -B -Dtest=Das28UtilTest,SerologyUtilTest,StudyNoUtilTest -DfailIfNoTests=true -Dsurefire.failIfNoSpecifiedTests=true clean test
rc=$?
end=$(date -u +%Y-%m-%dT%H:%M:%SZ)
printf 'start=%s end=%s exit=%s\n' "$start" "$end" "$rc"
```

`clean` 清掉本模块 `target/`，每次运行前确认其中没有需要保留的手工文件。不要以旧 XML 证明新调用。成功要求退出0、当前 `target/surefire-reports/TEST-*.xml` 恰为三个类，合计 tests=10、failures=0、errors=0、skipped=0；各 testcase 必须准确匹配：

- Das28UtilTest：cutPoints、labels（2）
- SerologyUtilTest：numbersByUln、operatorsAndText、unknownIsNull、subtype（4）
- StudyNoUtilTest：digits、lettersReplaceDigitsFromHighPosition、exhausted、build（4）

在同一模块 cwd，以刚记录的时间检查计数、方法和 XML 修改时间；断言失败即缺证，不能只看日志的 BUILD SUCCESS：

```sh
python3 - "$start" "$end" "$rc" <<'PY'
import datetime, sys, xml.etree.ElementTree as ET
from pathlib import Path
lo, hi = [datetime.datetime.fromisoformat(t.replace('Z', '+00:00')).timestamp() for t in sys.argv[1:3]]
assert int(sys.argv[3]) == 0
expected = {
    'com.wenwen.util.Das28UtilTest': {'cutPoints', 'labels'},
    'com.wenwen.util.SerologyUtilTest': {'numbersByUln', 'operatorsAndText', 'unknownIsNull', 'subtype'},
    'com.wenwen.util.StudyNoUtilTest': {'digits', 'lettersReplaceDigitsFromHighPosition', 'exhausted', 'build'},
}
files = sorted(Path('target/surefire-reports').glob('TEST-*.xml'))
assert len(files) == 3
counts = {k: 0 for k in ('tests', 'failures', 'errors', 'skipped')}
actual = []
for f in files:
    assert lo <= f.stat().st_mtime < hi + 1, ('非本次报告', str(f))
    suite = ET.parse(f).getroot()
    for k in counts:
        counts[k] += int(suite.attrib[k])
    actual.extend((t.attrib['classname'], t.attrib['name']) for t in suite.findall('testcase'))
assert counts == {'tests': 10, 'failures': 0, 'errors': 0, 'skipped': 0}, counts
assert len(actual) == 10 and set(actual) == {(c, m) for c, methods in expected.items() for m in methods}, actual
print(counts, sorted(actual))
PY
```

## 反例：受控断言失败

从仓库根建立忽略的独立副本，只复制相同 POM 与原有 Java/test 源。禁止复制 `src/main/resources`、application.properties、其他真实连接配置或凭据；不启动应用。

```sh
mkdir -p .tmp/ai-cohort-p00a
probe=$(mktemp -d .tmp/ai-cohort-p00a/failure-module.XXXXXX)
mkdir -p "$probe/src/main" "$probe/src/test"
cp raapi/pom.xml "$probe/pom.xml"
cp -R raapi/src/main/java "$probe/src/main/"
cp -R raapi/src/test/java "$probe/src/test/"
cat > "$probe/src/test/java/com/wenwen/util/ToolchainFailureProbeTest.java" <<'JAVA'
package com.wenwen.util;
import org.junit.jupiter.api.Assertions;
import org.junit.jupiter.api.Test;
public class ToolchainFailureProbeTest {
    @Test public void controlledFailure() {
        Assertions.fail("P00a controlled instrument failure");
    }
}
JAVA
(cd "$probe" && mvn -B -Dtest=ToolchainFailureProbeTest -DfailIfNoTests=true -Dsurefire.failIfNoSpecifiedTests=true clean test)
rc=$?
printf 'failure probe exit=%s\n' "$rc"
```

同样记录本次起止时间并检查新报告。预期退出非零；`$probe/target/surefire-reports/TEST-com.wenwen.util.ToolchainFailureProbeTest.xml` 中 tests=1、failures=1、errors=0、skipped=0，唯一方法为 controlledFailure，failure 的 message 包含 `P00a controlled instrument failure`。依赖或编译失败没有到达此断言，不能充作该负例通过。此 probe 不加入永久正常测试集。
