## 工程
- 后端 raapi：`vickywu0314/raapi`，Spring Boot 2.2 + MyBatis，**JDK 8** 编译（lombok 1.18.0 在 JDK 17+ 编译不过）。用户在 Eclipse 里跑 `RaApplication`，端口 8065。
- 前端 raweb：`vickywu0314/raweb`，纯静态 HTML/JS。用户本地在 `~/Desktop/raweb`，`npm install` + `npm run dev` → `http://127.0.0.1:8090`。
  `npm run dev` 是 `scripts/dev-server.mjs`：静态页面 + 把 `/api/` 转发到 `127.0.0.1:8065`（转发超时 60 秒）。前端 `API_BASE` 默认同源（空），不再写死后端地址。
- 两个仓库都直接推 `origin master`（用户已授权）；raapi 另同步推 `claude/serene-heisenberg-ug59gj`。推之前先 `git pull --rebase origin master`，不强推，只 `git add` 具体文件，一次提交一件事，提交说明用中文。
- 多人开发：另一位开发（用 Codex）通过 patch 文件给代码，用户把 patch 发过来，由我们先在临时 worktree 里 `git am --3way` 试打、编译、跑页面检查，再合进 master（保留作者 codex）。已合：raapi 4 个提交（AI 队列分析后端 P00~P03）、raweb 9 个提交（AI 队列分析前端 P00~P07）。
- 用户只要代码，数据库在用户本地（wenwen 库，与老系统共用、老系统仍在用）。云端沙箱用 MariaDB 模拟测试（root 密码同 application.properties）；用户本地是 MySQL 8。
